\# Task02: ETL процесс



Для корректной работы скрипта `db\\\_init.bat` на компьютере должны быть установлены:

1\. Python 3 (для генерации SQL-скрипта).

2\. SQLite3 (для создания базы данных).



\## Запуск

1\. Поместите исходные файлы датасета в папку `dataset/`.

2\. Сделайте скрипт исполняемым: `chmod +x db\\\_init.bat`

3\. Запустите скрипт: `./db\\\_init.bat`



После выполнения будет создана заполненная база данных `movies\\\_rating.db`.
